## Gotchas learned the hard way

- `impeccable.style` doesn't resolve on this machine — engine downloads
  via its GitHub fallback only (first run is slow, then cached).
- npm here is SLOW (minutes) and node_modules churn can kill the dev
  server — restart it if a background install kills port 3000.
- The 3.x Gemini models reject thinking-off; 503s are retryable (chatJson
  already retries; 429s back off adaptively).
- Prompt templates contain literal \n and " sequences — Edit-tool
  string matching fails on them; splice via a temp file + node when needed.
- Tests: `bun test`; tsc excludes tests/ (bun:test types).
- Commit messages end with the Co-Authored-By line (see CLAUDE.md).
